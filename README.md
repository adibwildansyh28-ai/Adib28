# ADIB SafeLink Resolver

Project Vercel tanpa database dan tanpa dependency eksternal.

## Deploy
1. Upload folder ini ke GitHub.
2. Import repository ke Vercel.
3. Framework: Other.
4. Deploy.

## Lokal Termux
npm i -g vercel
vercel dev

## Catatan
Resolver hanya mengikuti HTTP(S) `Location` redirect yang tersedia secara publik.
Tidak ada bypass CAPTCHA, login, token keamanan, atau iklan wajib pihak ketiga.
